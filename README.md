# 🌟 星星合成 · 玻璃瓶里的星光

一个在弧形玻璃瓶底中滚动、碰撞、合成的物理小游戏。灵感来自淘宝星星合成与小红书星光夜市，拥有真实的球体滚动惯性、玻璃球质感、十字星芒和局域网共享排行榜。

## ✨ 功能特性

- **点击释放**：点击屏幕任意位置，上方待命的星星会瞬移到该位置并开始下落。
- **同等级合成**：两个同等级玻璃球碰撞后合成为更高一级的星芒，最高 10 级。
- **真实物理滚动**：球体在弧形瓶底上自然滚动，向中心靠拢；碰撞时传递惯性。
- **玻璃球质感**：半透明玻璃外壳包裹十字星芒，内部星芒随球体整体旋转。
- **警戒线失败判定**：球堆超过警戒线并静止后游戏结束。
- **本地 / 局域网排行榜**：支持昵称录入，数据通过 Node.js 服务器在局域网内共享。
- **Docker 部署**：提供 Dockerfile，一键构建运行，数据可持久化。

## 🎮 游戏玩法

1. 游戏开始后，屏幕上方中央会出现一颗待命星星。
2. 点击画布任意位置，待命星星会瞬移到该位置并受重力下落。
3. 两个**相同等级**的星星碰撞后会合成一个更高等级的星星。
4. 合成后的星星会弹跳并继续滚动，直到稳定后才能再次参与合成（可配置为落地即可合成）。
5. 当有星星静止且顶部超过警戒线时，游戏结束。
6. 游戏结束后输入昵称，成绩会保存到局域网共享排行榜。

## 🛠 技术栈

- 前端：HTML5 Canvas + JavaScript（单文件）
- 后端：Node.js + Express（可选，若无依赖则使用内置 http 模块）
- 数据存储：服务器本地 JSON 文件（`data/leaderboard.json`）
- 部署：Docker
